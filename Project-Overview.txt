# Project Overview

This project is a **Python-based infrastructure automation tool** that automatically deploys a complete enterprise-style lab environment using **Microsoft Hyper-V**.

The system reads a configuration file (`ACME_Automation_Steps.json`) and builds an entire domain network automatically, including virtual machines, networking, directory services, storage systems, and security policies.

The environment includes:

* **Windows Server 2022** for domain infrastructure
* **Windows 11** for client systems
* **Ubuntu Server (Apache)** for web services
* **Active Directory** for identity and access management

Unlike traditional labs, **every component is built from scratch by the automation system**, including routers, servers, and storage systems.

# What the Project Automatically Builds

The system creates a **fully functional enterprise lab environment** that simulates real-world infrastructure.

# 🖥️ Virtual Infrastructure Creation

The program automatically provisions:

• Virtual network (Hyper-V switch)
• Router VM (AcmeRtr01)
• Primary Domain Controller (AcmePDC01)
• Secondary Server / Storage Node (AcmePDC02)
• Workstation VM (AcmeWks1001)
• Web Server VM (Ubuntu / Apache)

All systems are deployed via **PowerShell automation executed from Python**.

---

# 🌐 Automatic Router Creation

The router VM is fully automated and replaces the need for prebuilt appliances.

The router:

• is created dynamically
• has dual network adapters
• is configured for NAT
• routes traffic between lab and host network

Responsibilities:

• Default gateway for all lab systems
• Internet access via NAT
• Internal traffic routing

🧠 Module Responsibilities
core/

Handles all infrastructure orchestration and system-level automation logic.

hyperv_manager.py → VM lifecycle and Hyper-V control
vm_creator.py → VM creation logic
network_config.py → virtual networking
orchestrator.py → step execution pipeline
progress_tracker.py → deployment tracking
validators.py → environment validation

New Advanced Modules:

storage_manager.py → disk management, storage pools, RAID
backup_manager.py → backup and restore operations
dns_manager.py → DNS server configuration logic
linux_manager.py → Ubuntu server + Apache automation

domain/

Handles Active Directory and domain-level configuration.

ad_installer.py → AD DS installation and promotion
dhcp_config.py → DHCP scope configuration
ou_manager.py → OU creation
user_manager.py → users and groups

New Additions:

dns_records.py → A, CNAME, MX records
dhcp_reservations.py → DHCP reservations and WINS
infrastructure/

Handles post-deployment configuration and system behavior.

domain_join.py → domain joining
gpo_manager.py → group policy configuration
shares.py → shared folders

New:

failure_simulator.py → disk failures, RAID degradation, recovery
utils/

Provides low-level execution tools and helpers.

powershell_runner.py → executes PowerShell commands
ssh_runner.py → executes remote Linux commands (Ubuntu server)
checkpoint.py → step persistence system
logger.py → logging system
unattended/

Contains automated installation configuration files.

install_media/

Stores ISO files for:

Windows Server 2022
Windows 11
(Future: Ubuntu Server ISO)
LabVMs/

All virtual machines and disks are stored here for easy cleanup.

logs/

Stores deployment logs for debugging and auditing

# 🚀 Deployment Workflow

Full pipeline:

1. Load configuration
2. Create virtual network
3. Deploy router
4. Configure NAT
5. Deploy domain controller
6. Install AD, DNS, DHCP
7. Configure AD structure
8. Create users/groups
9. Deploy storage server (PDC02)
10. Configure disks and RAID
11. Create shares
12. Install backup system
13. Run backup job
14. Deploy Ubuntu web server
15. Configure DNS records
16. Configure DHCP advanced settings
17. Deploy workstation
18. Join domain
19. Apply GPOs
20. Run validation checks

# 🧹 Automated Lab Cleanup

The project includes a full teardown script:

```
.\destroy_lab.ps1
```

Removes:

• All VMs
• Virtual switches
• Disk files
• Entire lab directory

This enables:

• Rapid resets
• Clean testing cycles
• Repeatable deployments
